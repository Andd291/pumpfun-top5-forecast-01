A drift-diffusion Monte Carlo forecaster: it fits each new pump.fun coin's market-cap drift and volatility from the house's 10-minute snapshots, simulates every candidate to the seven answer reads, and writes rank probabilities and market-cap bin probabilities for the top 5.

## Run it

```sh
python3 main.py
```
